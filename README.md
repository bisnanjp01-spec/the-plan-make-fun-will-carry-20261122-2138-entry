A program that writes one 280-character plan to /output/entry.txt: selling missed-call text-back to US mobile auto detailers — $149 setup plus $29 a month, found on Google Maps, closed by text message. The edge is simple: a missed call is a lost job, so owners buy a same-day fix, and the bot — not the agent's hours — is the product.

## Run it

```sh
python3 main.py
```
